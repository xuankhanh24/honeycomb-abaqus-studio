# Desktop design contract

Operate mode: a native engineering workbench. Fluent/WinUI controls and system typography are visual authority; Linear-inspired restrained density and clear table hierarchy guide layout without replacing native Windows behavior.

NavigationView: Tổng quan, Tạo job, Job, Thư viện, Backup & cài đặt. Wide tables occupy the central workspace; a persistent details pane shows the selected run. Property groups expand into labeled input rows with units, sources and fixed/sweep/derived status. Primary actions name their effect. Destructive stop and retry are distinct from queue pause.

System theme is default. Use ThemeResource brushes, Segoe UI Variable, tabular number formatting, 8/16/24 px spacing. Show state with text and an icon as well as color. Unknown progress is indeterminate. Empty states explain the next available action. Errors retain entered data and expose a recoverable message and the log.

Charts use labeled axes, units, legends and unfiltered/raw provenance. Decimate only display series; exports retain original samples. Scientific contours use physical deformation scale 1 and explicitly labeled frame times.
